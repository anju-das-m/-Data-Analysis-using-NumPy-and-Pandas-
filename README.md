# Python DA Assignment 1 – Data Analysis using NumPy and Pandas

## 📌 Project Overview
This project focuses on practicing fundamental data analysis operations using Python libraries **NumPy and Pandas**. The assignment covers numerical computations, array manipulation, Series operations, and DataFrame exploration and modification.

## 🎯 Objectives
- Create and manipulate NumPy arrays.
- Perform numerical computations and statistical operations.
- Understand array indexing and slicing.
- Create and manipulate Pandas Series.
- Perform indexing using `loc` and `iloc`.
- Apply Boolean masking to filter data.
- Create and explore Pandas DataFrames.
- Perform filtering, grouping, and aggregation.
- Modify and delete DataFrame rows and columns.

## 🛠️ Tools & Technologies
- Python
- Jupyter Notebook
- NumPy
- Pandas

## 📊 Assignment Tasks

### 1. NumPy Array Operations
- Created a 1D array containing Week 1 temperature data.
- Inspected array shape, data type, and number of elements.
- Converted Celsius temperatures into Fahrenheit.
- Calculated maximum, minimum, and mean temperatures.
- Practiced array indexing and slicing.
- Created a 2D array containing temperature data for two weeks.
- Extracted weekly temperatures and weekend temperatures.

### 2. Pandas Series
- Created a Series named `marks` with custom rank indices.
- Accessed elements using integer positions.
- Retrieved values using `loc` and `iloc`.
- Applied Boolean masking to filter marks greater than 90.
- Modified the first-rank student's marks.
- Removed the last-rank entry.
- Calculated CGPA by dividing marks by 10.

### 3. Pandas DataFrame
- Created a DataFrame named `transactions`.
- Explored data using `head()`, `tail()`, `shape`, `columns`, and `dtypes`.
- Selected specific columns.
- Retrieved columns using indexing.
- Filtered transactions based on multiple conditions.
- Calculated category-wise value counts.
- Identified unique regions.
- Grouped transactions by region and calculated average amounts.
- Updated transaction amounts.
- Created a Discount column.
- Removed specific rows and columns.

- Performing mathematical and statistical calculations.
- Understanding Series and DataFrame structures.
- Working with indexing, slicing, and Boolean conditions.
- Applying data exploration and manipulation techniques.
- Using Pandas for practical data analysis tasks.
